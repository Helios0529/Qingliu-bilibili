### 清流 · B站 AI 内容过滤

Chrome 扩展，支持 B 站 AI 声明过滤、疑似视频补充屏蔽和自定义关键词。**当前版本：1.3.1**。

<img width="390" height="647" alt="image" src="https://github.com/user-attachments/assets/07a4857e-6f7f-4bb5-bf48-599e8e14eea7" />

## 功能

- **平台 AI 声明**：屏蔽或标注 B 站已声明的 AI 内容。
- **补充疑似AI视频**：勾选后，平台提示“疑似 AI”的视频也按屏蔽／标注模式处理；未勾选时仅提示。
- **自定义屏蔽词**：每行一个词，按标题匹配，命中显示“关键词屏蔽”。默认留空，最多 200 条。
- **单条放行**：输入 BV 号或视频链接添加，也可点击视频上的“放行”。列表默认折叠，支持移除，最多 500 条。
- **列表补位**：适配推荐、搜索、热门、排行榜等常见卡片，减少屏蔽后的留白。


## 安装

1. 从 Releases 下载 `BiliAI-Filter-1.3.1.zip` 并解压。
2. 打开 Chrome 的 `chrome://extensions`，开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择 **`extension` 文件夹**。
4. 刷新 B 站页面。更新时替换原目录的文件，再点击“重新加载”。

Chrome Web Store正在审核中。

## 使用

选择“直接屏蔽”隐藏匹配卡片，或“仅作标注”保留卡片。左下角可临时查看已屏蔽的视频；BV 放行优先于关键词和平台声明。主动打开视频时只显示独立提示，不隐藏播放器。

关键词需主动填写并点击“保存屏蔽词”；清空并保存即可停用关键词过滤。放行视频输入后点击“添加”或回车，展开“已放行视频”可移除记录。

未被 B 站声明的视频不会自动识别为 AI。填写过宽的关键词可能屏蔽讨论或批评相关主题的视频，可通过放行修正。站点改版和网络等待可能影响过滤时机，不改变 B 站服务器的推荐算法。

## 隐私与开发

设置、关键词、放行列表及声明缓存保存在本机。扩展按需直接向 B 站查询 BV 号和声明，不上传规则，不附带登录 Cookie，没有遥测或第三方识别服务。详见 [隐私说明](docs/PRIVACY.md)。
